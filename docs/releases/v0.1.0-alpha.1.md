# First public Go alpha

Replaces the TypeScript/npm implementation with an MIT-licensed Go module.
Historical npm versions remain in Git history and are not Go releases.

```sh
go get github.com/wooto/lol-replay-recorder@v0.1.0-alpha.1
```

- Windows amd64 local ROFL recording with a selected player's camera, explicit
  completion checks, context cancellation, and ffprobe output verification.
- Experimental opaque observer chunk/keyframe collection and persistent archives.
- HTTP replay handler for completed archives, with a loopback-only serving example.
- Optional Riot account/active-game discovery using caller-provided API credentials.
- Standard-library-only Go implementation; Windows CI, portable race checks,
  formatting, vet, and vulnerability scans.

**Experimental:** Current-patch KR archive playback and real-game FULL video
recording have not passed live acceptance. Observer archives are custom data
directories, not ROFL files; this release does not automatically launch an archive
into League or convert it into a video. Protocol-complete archives are not proof
of match-time-zero coverage. No Riot approval or future compatibility is claimed.

See the README and observer design notes for requirements and limitations.
